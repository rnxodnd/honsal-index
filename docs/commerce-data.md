# 춘천 편의·여가시설 데이터

사용자가 지정한 편의시설 11종과 여가시설 15종을 상권 원본의 소분류 코드로 분류했습니다. 결과는 **편의시설 2,200개, 여가시설 632개, 합계 2,832개**입니다. 기존 의료 524개·교통 1,896개와 합친 공통 분석 입력은 **5,252개·40종**입니다.

## 원본과 분류 기준

- 제공 파일: `소상공인시장진흥공단_상가(상권)정보_강원_202609.csv`
- 제공 기관: 소상공인시장진흥공단. [공공데이터포털 데이터 안내](https://www.data.go.kr/data/15083033/fileData.do)
- 자료 시점: 파일명에 표시된 **2026년 9월**. 일자는 확인되지 않아 공통 데이터의 `data_date`는 `2026-09`로 기록합니다.
- 원본: 109,517행·39열, 춘천시 전체 17,824행. UTF-8-SIG 인코딩입니다.
- 지역: `시도코드=51`, `시군구코드=51110`, `시군구명=춘천시`를 확인한 춘천 소재 업소입니다.
- 분류: `config/commerce_categories.json`의 소분류 코드·명칭 대응표를 사용합니다. 상호명으로 업종을 추정하지 않습니다.
- 원본 SHA-256: `48ec49f65e254b6abd4f069b7977b99afe2c9a2081bfb7486ddee9ad444efd22`
- Git에 공유된 LF 줄바꿈 원본 SHA-256: `2a2413200eee20dcdd54875353443349187d130166a48aed0fd65e47c1f516ce`

팀원이 저장소 루트에 올린 `소상공인시장진흥공단_상가(상권)정보_강원_202609.csv`를 Git으로 공유합니다. 개인 작업용 원본 `data/raw/gangwon_commerce_202609.csv`는 Git 추적에서 제외합니다. 두 원본의 모든 행·컬럼 값은 같고 CRLF/LF 줄바꿈만 다릅니다. 입력 검증에서는 CRLF를 LF로 정규화한 해시로 동일 자료인지 확인하며, 다른 내용 변경은 허용하지 않습니다. 결과의 `source_sha256`에는 실제로 읽은 파일 바이트의 해시를 기록합니다.

같은 좌표에 입점한 서로 다른 업소는 각각 유지합니다. 상가업소번호가 중복되는 자료는 확인 없이 합치거나 삭제하지 않습니다.

## 결과 파일과 컬럼

`data/processed/chuncheon_daily_life.csv`와 `data/processed/chuncheon_leisure.csv`는 다음 8개 컬럼만 포함합니다. 각각 편의시설과 여가시설을 확인하거나 전달할 때 사용합니다.

| 컬럼 | 의미 |
| --- | --- |
| 상가업소번호 | 원본 업소 식별자. 문자열로 보존 |
| 상호명 | 원본 상호명 |
| 업종 | 이번 분석의 구분: `편의시설` 또는 `여가시설` |
| 업종소분류명 | 원본 `상권업종소분류명` |
| 경도 | 원본 경도 |
| 위도 | 원본 위도 |
| 전화번호 | 원본에 전화번호 컬럼이 없어 빈 값 |
| 주소 | 도로명주소 우선. 없으면 지번주소 사용 |

**전화번호는 원본 미제공입니다.** 빈 값을 `0`이나 임의 번호로 채우지 않습니다. 선택된 2,832개 업소의 ID 중복, 상호·좌표·도로명주소 누락은 모두 0건입니다. 좌표가 있다는 사실과 실제 영업 여부·현장 위치 확인은 별개이며, 위 개수는 제공된 원본에 수록된 업소 기준입니다.

`data/processed/chuncheon_commerce_facilities.csv`는 위 자료에 `facility_id`, `name`, `city`, `lon`, `lat`, `phone`, `address`, `analysis_category`, `analysis_subtype`, `source_business_code`, `source_business_name` 및 출처 컬럼을 붙인 공통 형식입니다. 편의시설은 `daily_life`, 여가시설은 `leisure_community`로 연결합니다. 공통 시설 ID는 `chuncheon:commerce:`와 상가업소번호를 결합합니다.

앱은 의료·교통까지 합친 `data/processed/chuncheon_facilities_classified.csv` 하나를 분석 입력으로 사용합니다. 이 파일에 편의시설·여가시설 개별 CSV를 다시 합치면 중복됩니다. 전체 사용자 선택 목록과 자료 상태는 `facility_type_catalog.csv`, `facility_dataset_status.csv`에서 확인합니다.

## 다시 실행하기

프로젝트 루트에서 Python 3.12 가상환경을 활성화하고 다음 두 명령을 실행합니다. 첫 명령은 개인 원본 `data/raw/gangwon_commerce_202609.csv`가 있으면 사용하고, 없으면 저장소 루트의 공유 원본을 자동으로 사용합니다. 따라서 새로 clone한 팀원도 추가 파일 복사 없이 실행할 수 있습니다.

```bash
python src/data/prepare_commerce.py
python src/data/classify_facilities.py
```

다른 위치의 원본을 사용하려면 첫 명령에 `--input "원본 CSV 경로"`를 추가합니다. 원본에는 지정한 지역·업종 코드와 필요한 컬럼이 있어야 합니다. 두 번째 명령은 `chuncheon_commerce_facilities.csv`가 있으면 자동으로 포함합니다. 다른 공통 형식 상권 CSV를 사용하려면 `--commerce "분류된 CSV 경로"`로 지정합니다.

세부 시설 분류를 마쳤으므로 다음 단계는 위치를 격자에 연결하고, 사용자가 선택한 종류만 접근성 점수에 반영하는 것입니다. 시설 개수 자체를 0~100점으로 해석하지 않습니다.
