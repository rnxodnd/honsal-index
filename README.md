> 혼자 살아도 더 편안한 동네를 찾다.

## 해결하려는 문제

1인 가구가 동네를 선택하려면 생활시설, 대중교통, 의료시설, 여가시설의 위치를 따로 확인해야 합니다. 같은 동네라도 사용자가 자주 이용하는 시설 종류에 따라 편의가 달라집니다.

혼살지수는 이러한 정보를 비교 가능한 지표로 정리하여 다음 질문에 답하고자 합니다.

- 차량 없이 생활하기 편한 동네는 어디일까?
- 의료시설과 생활시설을 이용하기 좋은 동네는 어디일까?
- 내가 중요하게 생각하는 조건에 맞는 동네는 어디일까?
- 지역별로 어떤 생활 인프라를 개선해야 할까?

## 점수 설계

현재 분석 범위는 **생활시설·의료·교통·여가시설 네 항목**입니다. 안전성·주거 부담·별도 생활서비스 항목은 이번 구현에서 제외합니다. 생활시설과 여가시설은 수집 중인 상권 데이터의 세부 업종을 이용합니다.

사용자가 선택한 시설 종류별 접근성을 **높을수록 이용 여건이 좋은 0~100점**으로 변환하고, 같은 항목 안에서 평균을 낸 뒤 항목별 가중합을 계산합니다. 예를 들어 여가시설에서 당구장과 볼링장만 선택하면 탁구장은 지도·여가 점수·추천 근거에 반영하지 않습니다.

| 평가 항목 | 기본 가중치 | 평가 내용 |
| --- | ---: | --- |
| 생활시설 | 약 35.71% (5/14) | 상권 자료에서 선택한 편의점·마트 등 이용 여건 |
| 의료 | 약 21.43% (3/14) | 선택한 의료기관·약국 이용 여건 |
| 교통 | 약 28.57% (2/7) | 선택한 버스 정류장·전철/기차역 접근성 |
| 여가시설 | 약 14.29% (1/7) | 상권 자료에서 선택한 당구장·볼링장·탁구장 등 이용 여건 |

```text
종합점수 = 생활시설 × (25/70)
         + 의료 × (15/70)
         + 교통 × (20/70)
         + 여가시설 × (10/70)
```

위 비중은 기존 네 항목의 상대 비중 25:15:20:10을 유지하면서 합을 1로 재조정한 **초안**이며, 검증된 측정 척도가 아닙니다. 세부 지표와 표준화 방식은 실제 확보한 데이터를 검토한 뒤 확정합니다. 선택한 시설이 없는 항목은 계산에서 제외하고, 남은 항목의 가중치를 다시 합 1로 맞춥니다. 전체 시설을 하나도 선택하지 않으면 분석을 실행하지 않습니다.

### 데이터와 계산 원칙

- 자료가 없다는 이유로 해당 항목을 0점 처리하지 않습니다.
- 상권 자료의 세부 업종 코드·명칭을 보존하고, 선택한 시설 종류만 계산에 사용합니다. 시설 수가 많은 업종이 다른 업종을 압도하도록 원자료 개수를 단순 합산하지 않습니다.
- 같은 순위에서 비교하는 지역에는 동일한 평가 항목과 계산 기준을 적용합니다.
- 확보하지 못한 평가축은 제외 여부를 표시하고, 사용하는 가중치의 합을 100%로 조정합니다.
- 일부 평가축만 사용한 결과는 ‘확보된 항목 기반 시범 점수’로 표시합니다.
- 데이터 출처·기준일과 계산 방식을 함께 제공합니다.
- 테스트용 가상 데이터와 실제 지역 데이터를 구분합니다.

## 개발 환경 설치

**Python 3.12와 Git을 먼저 설치합니다.** `.venv/`는 각자의 컴퓨터에서 만들고 GitHub에는 올리지 않습니다. 공유하는 `requirements.txt`로 같은 패키지 버전을 설치합니다. 아래 Clone 명령은 처음 내려받을 때만 사용하며, 이미 Clone했다면 해당 폴더에서 가상환경 생성 단계부터 진행합니다.

macOS / Linux:

```bash
git clone https://github.com/rnxodnd/honsal-index.git
cd honsal-index
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip check
.venv/bin/python -c "import sys, streamlit, pandas; assert sys.version_info[:2] == (3, 12); assert sys.prefix != sys.base_prefix; print('Python:', sys.version.split()[0]); print('Streamlit:', streamlit.__version__); print('pandas:', pandas.__version__)"
```

Windows PowerShell:

```powershell
git clone https://github.com/rnxodnd/honsal-index.git
cd honsal-index
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -c "import sys, streamlit, pandas; assert sys.version_info[:2] == (3, 12); assert sys.prefix != sys.base_prefix; print('Python:', sys.version.split()[0]); print('Streamlit:', streamlit.__version__); print('pandas:', pandas.__version__)"
```

위 명령은 가상환경의 Python을 직접 사용하므로 별도 활성화가 필요 없습니다. 이미 `.venv`가 있다면 먼저 해당 Python의 `--version`으로 3.12인지 확인합니다. 다른 버전의 환경에 덮어 설치하지 않습니다.

VS Code에서는 프로젝트 폴더를 연 뒤 명령 팔레트의 **Python: Select Interpreter**에서 `.venv`의 Python 3.12를 선택합니다. 공유 설정에 기본 경로가 포함되어 있지만, 기존에 다른 인터프리터를 선택한 PC에서는 직접 다시 선택해야 합니다.

현재는 환경 준비 단계이며 실행할 웹 앱 진입점은 아직 없습니다. 앱 구현 후 이 문서에 실행 명령을 추가합니다. macOS 개발 환경에서 검증했으며 Windows·Linux에서의 실제 설치 확인은 각 팀원이 진행합니다.
