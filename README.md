# 혼살지수 | Honsal Index

> 혼자 살아도 더 편안한 동네를 찾다.

**강원도 1인 가구를 위한 생활 편의 점수·동네 비교·맞춤 추천 서비스**

여러 곳에 흩어진 생활 정보를 모아 동네별 생활 편의를 비교하고, 사용자의 우선순위에 맞는 지역과 추천 근거를 제공합니다.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 개발 기간 | 2026.10.30 13:00 ~ 2026.10.31 12:00, 총 23시간 |
| 참여 인원 | 4명 |
| 제출물 | 실행 가능한 프로그램 완성본, 발표자료 |
| 대상 지역 | 춘천·원주·강릉 중 데이터 확보가 가능한 1개 도시 |
| 비교 단위 | 읍·면·동 등 통일된 행정구역 기준 |
| 현재 단계 | 프로젝트 구조 및 개발 계획 준비 완료 |

## 해결하려는 문제

1인 가구가 동네를 선택하려면 생활시설, 대중교통, 의료시설, 주거비 등 다양한 정보를 따로 확인해야 합니다.

혼살지수는 이러한 정보를 비교 가능한 지표로 정리하여 다음 질문에 답하고자 합니다.

- 차량 없이 생활하기 편한 동네는 어디일까?
- 의료시설과 생활시설을 이용하기 좋은 동네는 어디일까?
- 내가 중요하게 생각하는 조건에 맞는 동네는 어디일까?
- 지역별로 어떤 생활 인프라를 개선해야 할까?

## 주요 기능

이번 개발에서 구현할 핵심 기능입니다.

| 기능 | 설명 |
| --- | --- |
| 생활 편의 지도 | 동네별 점수와 위치 확인 |

| 동네 비교 | 두 동네의 점수와 강점·부족 항목 비교 |

AI 질의응답과 추가 도시 지원은 핵심 기능 완성 후 검토합니다.

## 점수 설계

각 항목을 **높을수록 생활 여건이 좋은 0~100점**으로 변환한 뒤 가중합을 계산합니다.

| 평가 항목 | 기본 가중치 | 평가 내용 |
| --- | ---: | --- |
| 생활시설 | 25% | 편의점·마트·세탁소 등 생활시설 이용 여건 |
| 교통 | 20% | 정류장·노선 등 대중교통 이용 여건 |
| 의료 | 15% | 병원·약국 등 의료시설 이용 여건 |
| 안전 관련 인프라 | 15% | 가로등·CCTV 등 관련 시설 현황 |
| 주거 부담 | 15% | 주거비 부담이 낮을수록 높은 점수 |
| 여가·커뮤니티 | 10% | 공원·도서관·문화시설 이용 여건 |

```text
종합점수 = 생활시설 × 0.25
         + 교통 × 0.20
         + 의료 × 0.15
         + 안전 관련 인프라 × 0.15
         + 주거부담 완화 × 0.15
         + 여가·커뮤니티 × 0.10
```

위 비중은 기획안에 따른 초기 설정입니다. 세부 지표와 표준화 방식은 실제 확보한 데이터를 검토한 뒤 확정합니다.

### 데이터와 계산 원칙

- 자료가 없다는 이유로 해당 항목을 0점 처리하지 않습니다.
- 같은 순위에서 비교하는 지역에는 동일한 평가 항목과 계산 기준을 적용합니다.
- 확보하지 못한 평가축은 제외 여부를 표시하고, 사용하는 가중치의 합을 100%로 조정합니다.
- 일부 평가축만 사용한 결과는 ‘확보된 항목 기반 시범 점수’로 표시합니다.
- CCTV·가로등 현황을 실제 범죄 위험을 직접 측정한 결과로 표현하지 않습니다.
- 데이터 출처·기준일과 계산 방식을 함께 제공합니다.
- 테스트용 가상 데이터와 실제 지역 데이터를 구분합니다.
