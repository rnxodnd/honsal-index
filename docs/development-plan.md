# 혼살지수 개발 계획

**마감 반영:** 개발 기간은 2026-10-30 13:00 ~ 2026-10-31 12:00(KST), 팀은 4명, 제출물은 실행 가능한 프로그램과 발표자료입니다. 아래는 전체 설계 방향이며, 이번 작업의 범위·역할·시간 배분은 [23시간 완성 계획](23-hour-plan.md)을 우선합니다. 다도시 확장과 AI 질의응답은 이번 마감의 필수 기능이 아닙니다.

## 기획안에서 확인한 목표

강원도 읍·면·동의 생활 편의를 0~100점으로 비교하고, 사용자 조건에 맞는 동네와 추천 근거를 제공합니다. 주민의 정착 선택과 지자체의 생활 인프라 개선 판단을 돕는 것이 목적입니다.

기획안의 주요 사용자는 청년·무차량·여성·고령 1인 가구 및 지자체 담당자입니다. 핵심 흐름은 **조건 입력 → 지도 탐색 → 동네 비교 → 맞춤 추천**입니다.

2026-10-30 사용자 결정에 따라 대상은 **춘천시**, 분석 항목은 **생활시설·의료·교통·여가시설**로 확정했습니다. 안전성·주거 부담·별도 생활서비스 항목은 이번 구현에서 제외합니다. 원본 기획안 PDF는 초기 제안 기록으로 보존하며, 현재 구현 범위는 이 문서를 따릅니다.

상권 자료에서 생활시설과 여가시설을 분류하고, 당구장·볼링장·탁구장 등 세부 종류를 사용자가 선택하게 합니다. 선택 결과는 지도·점수·동네 비교·추천에 동일하게 적용합니다. 상세 계약은 [시설 선택과 분석 규칙](facility-selection.md)을 따릅니다.

## 기본 점수 구성

| 항목 | 기본 비중 초안 | 사용할 자료 | 설계할 평가 방법 |
| --- | ---: | --- | --- |
| 생활시설 | 5/14 (약 35.71%) | 상권 자료의 편의점·마트 등 세부 업종과 좌표 | 선택 종류별 접근성 점수의 평균 |
| 의료 | 3/14 (약 21.43%) | 의료기관·약국 위치와 기관 종류 | 선택 종류별 접근성 점수의 평균 |
| 교통 | 2/7 (약 28.57%) | 버스 정류장·전철/기차역 위치 | 선택 교통시설 접근성 |
| 여가시설 | 1/7 (약 14.29%) | 상권 자료의 당구장·볼링장·탁구장 등 세부 업종과 좌표 | 선택 종류별 접근성 점수의 평균 |

시설 종류별 접근성을 먼저 **높을수록 이용 여건이 좋은 0~100점**으로 변환합니다. 항목 안에서는 사용자가 선택한 종류의 점수만 평균 내고, 네 항목을 모두 선택한 경우 다음과 같이 합산합니다.

```text
종합점수 = 생활시설 × (25/70) + 의료 × (15/70)
         + 교통 × (20/70) + 여가시설 × (10/70)
```

기본 비중은 `config/weights.json`에 보관합니다. 기존 활성 항목의 상대 비중 25:15:20:10을 합 1로 재조정한 초안이며 검증된 측정 척도가 아닙니다. 선택 시설이 없는 항목은 제외하고 남은 가중치를 다시 합 1로 맞춥니다. 개인화 가중치는 음수를 허용하지 않습니다. 전체 시설이 무선택이거나 활성 항목의 가중치 합계가 0이면 분석을 실행하지 않고 입력을 안내합니다.

당구장과 볼링장만 선택했다면 탁구장은 지도·점수·추천 근거에서 제외합니다. 반경 내 시설 개수를 업종 구분 없이 합산하지 않으며, 선택 종류별 지표를 계산할 수 있도록 원본 시설 행과 세부 업종 코드를 보존합니다.

## 계산 전에 확정할 사항

- **지역 기준:** 행정동·법정동의 차이를 확인하고, 동일 기준일의 행정코드와 경계를 사용합니다. 지역명만으로 데이터를 합치지 않습니다.
- **공간 집계:** 읍·면·동 전체 시설 수를 도보 접근성으로 해석하지 않습니다. 거주지 또는 주거 격자에서의 접근성을 구한 뒤 지역별 집계 방식을 정합니다.
- **거리·시간:** 직선거리를 실제 도보 10분으로 표시하지 않습니다. 경로 자료가 없으면 사용한 거리 기준과 추정 방식을 명시합니다.
- **방향성:** 시설까지의 거리는 작을수록 유리합니다. 원자료 값과 최종 점수 방향을 구분합니다. 확보한 위치 자료에 없는 영업시간·배차간격을 추정해서 채우지 않습니다.
- **정규화:** 도시가 추가되어도 비교가 가능한 기준을 정하고 버전을 기록합니다. 도시마다 별도로 계산한 상대점수를 그대로 합쳐 순위를 만들지 않습니다.
- **결측:** 자료 없음과 실제 시설 0개를 구분합니다. 검증 전에는 필요한 항목이 없는 지역의 종합점수를 산출하지 않는 보수적인 방식을 기본안으로 둡니다. 데이터 충족률과 누락 항목을 함께 표시합니다.
- **시설 분류:** 상권의 원본 세부 업종 코드·명칭과 분석용 분류를 함께 남깁니다. 확인되지 않은 업종을 임의로 생활시설·여가시설에 배정하지 않습니다.
- **기본점수·개인화:** 두 점수를 화면에서 구분하고, 비교할 때 같은 가중치·기준일·계산 버전을 적용합니다.
- **추천 설명:** 추천 사유와 약점은 계산된 항목에서 생성합니다. 기획안의 예시 지역 점수는 실제 관측 데이터로 사용하지 않습니다.

## 데이터 조사 체크리스트

의료기관·약국과 버스 정류장·철도역 자료는 확보했습니다. 상권의 생활·여가시설 분류와 공간 집계용 경계·격자 검증을 이어갑니다.

| 범주 | 확보할 내용 | 처음 확인할 문제 |
| --- | --- | --- |
| 지역 기준 | 읍·면·동 경계, 행정코드, 기준일 | 경계와 코드의 일치 여부 |
| 생활·여가시설 | 상권 시설 ID·원본 세부 업종 코드/명칭·분석용 분류·위치 | 선택 가능한 종류 목록, 분류 누락, 중복·좌표 누락 |
| 의료 | 의료기관·약국 위치와 종류 | 원본 종류 보존, 기관 ID·좌표·기준일 |
| 교통 | 버스 정류장·전철/기차역 위치와 ITX 정차 표시 | 같은 역의 전철·기차 중복 집계 방지, 좌표·서비스 기준일 구분 |

수집할 때 데이터 이름, 제공 기관, 원문 URL, 수집일, 자료 기준일, 이용 조건, 지역 범위, 좌표계, 컬럼 설명을 함께 기록합니다. 원본은 `data/raw/`, 정제 결과는 `data/processed/`에 저장합니다. 재수집과 재계산이 가능하도록 처리 코드를 `src/`에 남깁니다.
